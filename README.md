## 🔐 Real Firebase Authentication (Modular SDK v10+)

The application has been transformed from mock/simulated states to a **100% REAL, production-ready Firebase v10 system** (`firebase-init.js`):

1. **Modular SDK Architecture:**
   - Powered by official Firebase Modular SDK v10 (`firebase/app`, `firebase/auth`, `firebase/firestore`).
   - Dynamic credentials fetch via `/api/config` backed by server-side `.env` variables (`FIREBASE_API_KEY`, `FIREBASE_AUTH_DOMAIN`, etc.).

2. **Google OAuth (1-Click Social Sign-In):**
   - Configured with `GoogleAuthProvider` and `signInWithPopup(auth, provider)`.
   - Opens the official Google Account Selector popup in real time.
   - Dynamically captures real Google profile photo (`photoURL`), `displayName`, and verified `email`.
   - Syncs profile directly into Cloud Firestore (`users` collection).

3. **Email/Password Authentication & Verification:**
   - Implemented via `createUserWithEmailAndPassword()` and `signInWithEmailAndPassword()`.
   - **Automatic Email Verification Link:** `sendEmailVerification(user)` is dispatched immediately upon sign up.
   - **Strict Verification Guard:** If `!user.emailVerified`, bookings are blocked with the prompt:
     > *"Please verify your email via the link sent to your inbox before proceeding with bookings."*
   - Interactive verification management:
     - **"Check Verification Status"** calls `user.reload()` and validates `user.emailVerified`.
     - **"Resend Verification Link"** calls `sendEmailVerification()`.
     - **"Forgot Password"** dispatches real password recovery links via `sendPasswordResetEmail()`.

4. **Real-Time Session State (`onAuthStateChanged`):**
   - Persists session state across page reloads.
   - Dynamically renders real Google Profile Photo / Initials, name, email, and verification status in both desktop and mobile navigation bars.
   - Clean `signOut(auth)` with instant session termination and state reset.

## 🛡️ Real-Time Booking Guard & Auto-Resume

- Protects all room and dining reservation actions (`"Book Mandakini"`, `"Book Paishwani"`, `"Book Vaidehi"`, `"Book Panchvati"`, `"Pre-Book Thali"`):
  - **Unauthenticated Users:** Intercepted immediately with the real Firebase Auth Modal; the intended room/rate is stored in `sessionStorage` (`ask_intended_booking`).
  - **Unverified Users:** Intercepted with the Email Verification Prompt Modal.
  - **Seamless Auto-Resume:** Upon successful authentication and verification, the system retrieves `ask_intended_booking`, auto-opens the exact reservation drawer, and pre-fills the guest's verified name and email.

## 💳 Real Razorpay Payment Gateway (Full-Stack Flow)

1. **Client-Side Setup:**
   - Official Razorpay SDK: `https://checkout.razorpay.com/v1/checkout.js`.

2. **Backend Order Creation Route (`POST /api/create-razorpay-order`):**
   - Initialized with official `razorpay` npm package using `process.env.RAZORPAY_KEY_ID` and `process.env.RAZORPAY_KEY_SECRET`.
   - Server-side rate verification against official catalogs (`ROOM_CATALOG` & `DINING_CATALOG`).
   - Strict calculation in paise including:
     - **12% GST** for luxury suites / rooms.
     - **5% GST** for Satvik Dining / Panchvati Rasoee orders.
   - Calls `razorpay.orders.create({ amount, currency: "INR", receipt: ... })` and returns the real `order.id` to the frontend.

3. **Backend Signature Verification Route (`POST /api/verify-payment`):**
   - Validates digital signatures using HMAC SHA-256 (`crypto.createHmac('sha256', secret).update(order_id + '|' + payment_id).digest('hex')`).
   - Rejects tampered or unverified transactions before confirming bookings.

4. **Confirmation & Luxury Digital Voucher:**
   - Displays real reference number (`ASK-2026-XXXX`), `razorpay_payment_id`, verified amounts, and print/download receipt button.
